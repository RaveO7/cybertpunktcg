# Textes et traductions

- Aucun texte d'interface en dur : `useTranslations("bloc")` (client) ou `await getTranslations("bloc")` (serveur) ; dates, prix, nombres via `useFormatter()` / `getFormatter()`.
- Le français est la référence : une clé ajoutée va d'abord dans `src/i18n/messages/fr/<bloc>.json`, puis, traduite, dans `en`, `de`, `es`, `it`, avec les **mêmes variables**. Nouveau bloc : l'ajouter aussi à `messages/fr/index.ts`.
- Respecter `src/i18n/GLOSSARY.md` pour les termes de jeu.
- ICU : pluriels `{n, plural, one {…} other {…}}` ; accolades littérales (mots-clés comme `{Go Solo}`) entourées d'apostrophes `'{Go Solo}'` dans un message lu avec `t()`, mais pas dans les contenus lus avec `t.raw()`.
- Clé supprimée : la retirer des 5 langues.
- Vérifier : `npx vitest run tests/unit/i18n-messages.test.ts tests/unit/i18n-rules-terms.test.ts`. Textes de règles des cartes (`src/i18n/cards/`) : `npx tsx scripts/check-card-translations.ts`.
