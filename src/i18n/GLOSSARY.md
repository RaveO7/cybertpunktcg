# Glossaire des termes de jeu

Référence pour toutes les traductions du site (interface, règles, tutoriel, partie guidée, texte de
règles des cartes). La colonne française reprend **l'impression française officielle** des cartes
(relevée dans la base, impressions `language = "fr"`). Il n'existe pas d'édition officielle en
allemand, espagnol ou italien : ces colonnes suivent la même stratégie que l'édition française.

## Principes

1. **Ne jamais traduire** :
   - les mots-clés entre accolades, tels qu'imprimés : `{Call}`, `{Go Solo}`, `{Play}`, `{Attack}`,
     `{Defeated}`, `{Spend}`, `{Blocker}`, `{Quick}`, `{Adrenaline}`… ;
   - les affiliations en majuscules : `ARASAKA`, `BRAINDANCE`, `CORPO`, `CYBERWARE`, `GANGER`, `MERC`,
     `ROCKER`, `AI`, `DRONE`, `VEHICLE`… ;
   - les noms de cartes (l'impression anglaise fait foi faute d'impression dans la langue) ;
   - les termes que l'édition française garde en anglais : **Gig**, **Power**, **Gear** (dans le texte
     des cartes), **Eddie(s)**, **€$**, **Street Cred** (☆), **Fixer**, **Call** (verbe : « Call une
     Légende »), **d4 / d6 / d8 / d10 / d12 / d20**, **RAM**, **deck**.
2. **Traduire** les types de carte, les zones et les verbes d'action, toujours par le même mot.
3. **Nombres et signes** : identiques à la source (« +2 Power », « 8+ », « jusqu'à +2 », « -1 €$ »).
4. **Personne** : le français officiel vouvoie (« Piochez 1 ») ; l'allemand, l'espagnol et l'italien
   tutoient, comme l'interface du site et l'usage des jeux de cartes (« Ziehe 1 », « Roba 1 »,
   « Pesca 1 »).
