## Sans effet selon Google (ne rien faire)

Longueur des titres et descriptions (Google tronque à l'affichage, pas de pénalité) ; balise `keywords` ; longueur du contenu ; ordre ou nombre de `h1`/`h2` ; TLD ; sous-domaine ou sous-répertoire.
→ Les 288 titres et 127 descriptions « trop longs » de l'audit précédent ne sont **pas** un problème de classement.

## À faire, par ordre d'impact

1. **Google Search Console** (impact fort, aucune configuration aujourd'hui). Seul moyen de savoir combien de pages sont indexées, et pourquoi les autres ne le sont pas (« Explorée, actuellement non indexée »). Sur `*.vercel.app`, propriété « préfixe d'URL » vérifiée par balise meta ou fichier HTML (la propriété de domaine exige le DNS, impossible). Puis envoi du sitemap.
2. **Valeur propre des fiches cartes** (risque principal). Les règles anti-spam citent la génération de pages « from feeds » et la traduction automatique (« synonymizing, translating ») comme abus de contenu à grande échelle si les pages n'apportent rien de plus. Les fiches ont ~280 mots : texte de règles (celui de l'éditeur), coût, affiliations, prix Cardmarket, cartes liées. Atouts déjà présents : traductions relues (glossaire, impression française officielle), prix. Pistes : historique de prix visible, versions et raretés, decks qui jouent la carte, règles et précisions de jeu. À mesurer dans la Search Console avant de lancer un chantier.
3. **Nom de domaine** (impact moyen, à décider tôt). `cybertpunktcg.vercel.app` (faute « cybert »). Google ne garantit pas le nom de site pour un sous-domaine d'hébergeur partagé. Un changement plus tard reste possible (redirections 301 gardées au moins un an, outil de changement d'adresse) avec quelques semaines de fluctuation ; plus tôt il est fait, moins il coûte.
4. **Liens entrants** : aucun site tiers ne liste les cartes du jeu dans les recherches testées (le site officiel cyberpunktcg.com et sa base Netdeck.gg dominent, un blog de fan existe). Discord officiel, blogs de fans, Reddit : se faire citer, sans excès (Google : « you can overdo promoting your site »).

## Points mineurs

- Le sitemap n'a pas de `x-default` alors que le HTML en a un : sans gravité (une méthode suffit), mais les deux pourraient être alignés.
- Nom du site dans les résultats : WebSite déjà présent sur l'accueil (`name`, `url`) ; ajouter `alternateName` est recommandé.
- Product (prix) : non pertinent sans offre de vente sur la page ; garder CreativeWork.
- Core Web Vitals : utilisés par le classement, sans poids publié ; sans trafic suffisant, pas de données de terrain (CrUX). Lighthouse reste un diagnostic (voir `2026-11-22-audit-lighthouse.md`).
